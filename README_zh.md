# PlantAgentBench 演示

[打开网页](https://changcv2021.github.io/PlantAgentBench/)

本页展示 **50 道固定案例、11 种模型配置的 501 条已有轨迹**，P1–P5 各 10 道。可在同一道题上自由切换模型：绿色为 **Ours · Qwen3.5-9B (Thinking)**，蓝色为开放权重模型，暖棕色为闭源模型。Ours 的基础模型为 Qwen3.5-9B，使用 Kimi2.6 轨迹 SFT，检查点为 `export-844`。

Ours、Qwen3.5-9B 原生工具调用版、Qwen3.5-9B JSON 版、Qwen3.5-27B、Kimi2.6、Gemma4-31B、Claude Opus 5.5、GPT-5.4、GPT-6-Astra 和 Grok 4.7 均有 50 条对应记录。Muse Glimmer 30B 只有 1/50，其余明确标为没有可用回放。这是当前演示案例的覆盖数，不代表完整 Benchmark 的完成进度。

选择模型、任务和案例后，可逐步查看初始观察、模型保存的思考文本、工具选择、环境反馈、新获得的证据以及最终提交。P5 展示真实归档记录的分阶段开放。页面也支持自动播放、图像放大、证据引用跳转和单条回放下载。

切换模型保持同一案例，回到初始观察。每个案例上方直接展示本题全部已登记图片，包括模型未主动查看的图片，并标明实际查看步骤或“本轮未查看”。点击可放大，或跳转到对应取图步骤。图片预览面向网页读者，下面的 Agent 回放仍保留原始逐步可见性。本身没有图像的测量或文本任务明确显示“本题无图片”；默认进入有图的 P3 案例。

这是精选案例展示，每条保留原始成功或失败结果，不代表总体成功率。回放直接使用已保存的模型输出，没有重新推理、改写答案或修改评分规则。模型生成的思考与结论也不等同于独立植物专家的确认。

此仓库只发布演示代码和选定回放；暂不发布完整题库、私有 Gold、模型权重或原始服务请求。公开的 50 个题目 ID 见 `demo_manifest.json`，后续研究应记录这些题目已公开曝光；本次没有改动原冻结测试集。

下一阶段计划发布模型并接入 Hugging Face GPU，让访客上传图片和问题。为降低体验门槛，首批在线能力计划限于 **P3 诊断、P4 护理决策**；P1/P2/P5 通常还需要测量、环境或连续时间记录。本次网页没有启用上传与实时推理，也不会调用付费接口。

本地直接打开 `docs/index.html` 即可；GitHub Pages 发布 `main` 分支的 `docs/`。代码采用 MIT 许可，来源证据按各自原始条款使用，详见 [DATA_TERMS.md](DATA_TERMS.md)。


## 第四版：P2 增加五个原始带图案例

保留第三版的 45 个案例，只替换 P2 中的 5 个。新增案例来自同一冻结 Core-3K v2 和同一微调模型的已有轨迹。允许选择未成功的案例，页面逐条展示真实任务结果；没有最终报告时也明确标注。不重新调用模型或评分。

P1 保持原样。P2 包含 5 个带图任务和 5 个纯记录任务。新增 5 个任务的 Ours 原评分均为成功，真实动作都是 QUERY → QUERY → SUBMIT，模型没有查看图像；图片标明“本轮未查看”，不能解释成视觉推理轨迹。模型未查看的图片明确标注为访客预览。案例及图片清单见 [DEMO_SELECTION.md](DEMO_SELECTION.md)。

## 第五版：同题切换模型

每个模型使用各自真实的动作、证据、最终报告和既有评分，包括失败和无最终提交的情况。图片是否看过、何时看过也按模型独立显示。原生工具调用与 JSON 运行分别标注，不能把这个精选回放页当成受控排名。思考文本仅展示服务实际返回且可从记录读取的内容；返回的推理摘要单独标注，不补写隐藏思考。当前 50 道案例和 Ours 的原始轨迹保持不变。

## 第六版：Thinking 标注与已有结果核查

- **Qwen3.5-9B**：全量 JSON 动作运行，thinking 关闭，单次输出上限 4,096 tokens。
- **Qwen3.5-9B (Thinking)**：Core-3K 原生工具调用运行，thinking 开启，单次输出上限 32,768 tokens。
- **Ours · Qwen3.5-9B (Thinking)**：基于 Qwen3.5-9B 的 thinking 模式，以 Kimi2.6 轨迹进行 SFT。

两种基线还具有不同的采样配置，不能将差异单独归因于 thinking。模型按钮上的 50/50 等覆盖数已去掉。[MODEL_COVERAGE.md](MODEL_COVERAGE.md) 保留全量运行进度检查点与当前 50 道题的真实回放覆盖核查，集成测试不替代正式任务结果。原始轨迹、答案和评分不变。
