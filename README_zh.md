# PlantAgentBench 演示

[打开网页](https://changcv2021.github.io/PlantAgentBench/)

本次先发布 **50 个真实成功案例的交互回放**，P1–P5 各 10 个。执行模型是使用 Kimi2.6 轨迹微调的 Qwen3.5-9B，检查点为 `export-844`；这些不是 Kimi 本身的答题轨迹。

选择任务和案例后，可逐步查看初始观察、模型保存的思考文本、工具选择、环境反馈、新获得的证据以及最终提交。P5 展示真实归档记录的分阶段开放。页面也支持自动播放、图像放大、证据引用跳转和单条回放下载。

每个案例上方现在直接展示本题全部已登记图片，包括模型未主动查看的图片，并标明实际查看步骤或“本轮未查看”。点击可放大，或跳转到对应取图步骤。图片预览面向网页读者，下面的 Agent 回放仍保留原始逐步可见性。本身没有图像的测量或文本任务明确显示“本题无图片”；默认进入有图的 P3 案例。

这是精选成功案例展示，不代表总体成功率。回放直接使用已保存的模型输出，没有重新推理、改写答案或修改评分规则。模型生成的思考与结论也不等同于独立植物专家的确认。

此仓库只发布演示代码和选定回放；暂不发布完整题库、私有 Gold、模型权重或原始服务请求。公开的 50 个题目 ID 见 `demo_manifest.json`，后续研究应记录这些题目已公开曝光；本次没有改动原冻结测试集。

下一阶段计划发布模型并接入 Hugging Face GPU，让访客上传图片和问题。为降低体验门槛，首批在线能力计划限于 **P3 诊断、P4 护理决策**；P1/P2/P5 通常还需要测量、环境或连续时间记录。本次网页没有启用上传与实时推理，也不会调用付费接口。

本地直接打开 `docs/index.html` 即可；GitHub Pages 发布 `main` 分支的 `docs/`。代码采用 MIT 许可，来源证据按各自原始条款使用，详见 [DATA_TERMS.md](DATA_TERMS.md)。
