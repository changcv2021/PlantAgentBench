About these demonstrations

Ten shared cases per task. Switch models while keeping the same case, then step through the actions each agent actually took. Green marks Ours, blue marks open-weight models, and purple marks closed-source models. Both successes and failures are preserved. This curated gallery is not a representative performance sample or a model leaderboard.

Selection, provenance and data credits

Ours is based on Qwen3.5-9B in thinking mode, fine-tuned on Kimi2.6 trajectories (checkpoint export-844). The same 50 cases remain fixed across models. Original model outputs, tool calls, returned evidence and saved evaluation outcomes are retained. Unavailable recordings are explicitly labelled; no other model's trace is substituted.

Run configurations differ: Qwen3.5-9B (Thinking) uses native tool calls with thinking enabled; Qwen3.5-9B uses JSON actions with thinking disabled. Ours uses the thinking base. These runs also differ in output limits and sampling settings, so this is not an isolated test of thinking mode. Recorded reasoning is shown only when the service actually returned it. Cross-model replays illustrate behavior, not a controlled performance comparison.

P1 remains record-based. Five P2 cases have archived images; Ours queried records without inspecting those images. Every model's gallery independently labels what that model saw. No inference or rescoring was performed for this release. Private reference answers and model weights are not included.
