About these demonstrations

Ten recorded runs per task. Five P2 cases include archived images. In these saved runs the agent queried records without inspecting the images; the gallery labels them accordingly. This is a curated gallery, not a representative performance sample. Original model outputs, tool calls and observations are preserved.

Selection, provenance and data credits

The acting model is Qwen3.5-9B, fine-tuned on Kimi2.6 trajectories (checkpoint export-844). Runs come from frozen Core-3K v2. Each case retains the outcome assigned by the existing task evaluator. We prioritize useful evidence acquisition, varied tools, explicit evidence references and, for follow-up tasks, assessment across recorded stages. Repeated queries and unnecessarily long runs are less useful for this demonstration.

P1 remains record-based; P2 includes five tasks with available images and five record-only tasks. The saved P2 agent runs use records, not image inspection. No trajectories were generated or repaired for this release. Private reference answers and model weights are not included.
