ONE ENVIRONMENT, DIFFERENT INVESTIGATIONS

The agent chooses
its next step.

The task supplies an initial observation and a finite set of accessible evidence. What the agent asks for — and when it decides to submit — is visible in the replay.

01

Start with what is known

Read the task and its initial records. Unrequested images and later-stage records stay outside the agent’s visible evidence.

02

Investigate deliberately

Inspect an image, query a measurement, or search reference knowledge. Follow the actual tool arguments and the evidence returned.

03

Commit to a decision

Review a stage assessment or final report, including cited evidence. Longitudinal episodes reveal existing records in stages.

ABOUT THIS RELEASE

Real trajectories.
A focused first release.

The acting model is Qwen3.5-9B fine-tuned using Kimi2.6-generated trajectories (checkpoint export-844). These recordings come from the frozen PlantAgentBench Core-3K v2 evaluation, using native tool calls and thinking.

Each selected case passed its existing task evaluator. Success refers to the benchmark’s task requirements, not independent confirmation of every biological statement. The selection is intentionally successful and should not be used to infer benchmark-wide accuracy.

The viewer shows the original model’s recorded reasoning, actions, and visible evidence. It does not publish private reference answers or the full benchmark. The 50 exposed episode IDs are listed in the repository so future evaluations can account for their public availability.
